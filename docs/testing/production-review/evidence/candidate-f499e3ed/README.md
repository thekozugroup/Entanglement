## Changes and local verification

The coordinator can link an online Tailscale device to an already paired Entanglement identity with `entangle mesh tailnet link <stable-node-id> --peer <paired-peer-id> --port <worker-udp-port>`. The command checks the trusted peer, selects a compatible tailnet address, serializes configuration writes and preserves unrelated settings. Repeating the same link leaves the file untouched. Enable the Tailscale transport and restart the coordinator to load a new mapping. In the private network, the exact release CLI enrolled the worker, a signed JSON Pointer request returned its nonce from that worker, and revocation denied subsequent work. [Operator instructions](../../../../operations.md#running-a-worker-on-a-tailnet) · [Live enrollment receipt](private-tailnet-ordinary-receipt.json)

Signed work resumed 3.146 seconds after worker overlay recovery and 1.484 seconds after coordinator overlay recovery. The bridge delivered 64 bytes, exhausted its signed grant and denied the next transfer. All participants shared one physical Linux host. ## Performance

Four of seven signed workload routes met both engineering limits against `a5728c23`. Every route met the throughput limit. The allowed p95 latency increase was 5 percent. Observed increases were 6.31 percent for a single-client remote greeting, 6.51 percent for local image resize and 8.00 percent for image resize on one remote worker. In 12 fresh profiles, linking a peer took 10.852 ms at p95. Repeating an existing link took 7.465 ms at p95. Each command made one local status request, and no repeat rewrote its configuration. The comparator is a prior engineering release. A production baseline still needs operator approval. [Seven workload routes](engineering/performance-interpretation.md) · [Operator measurements](tailnet-link-latency/release/receipt.json)

The sensitivity experiment ran 20 alternating candidate and reference arms, including identical-reference controls. All 2,880 PNG hashes and worker selections passed. The one-remote image p95 candidate/reference median was 1.067 with a range of 0.873 to 1.365. The local image median was 0.775. Neither route met the registered conditions for attributing a consistent adverse latency effect to the candidate. [Schedule and raw results](image-sensitivity/README.md)

The genuine-camera benchmark used a Canon CR2 and Nikon NEF. Five single- or three-worker batches validated both photos and their 18 tiles, including two warmups. The run then failed its requirement that all three allowlisted workers appear in the tile receipts.
