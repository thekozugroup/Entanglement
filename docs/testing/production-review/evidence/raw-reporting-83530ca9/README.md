# RAW benchmark reporting

The benchmark now preserves observations when a completed camera batch misses its specified worker coverage or its output comparison fails. The report records processed photographs, elapsed times, tile counts for every specified worker, observed hashes and the exact filenames whose bytes differ. It identifies missing sources and missing reference entries separately. Workers can be absent from a batch for several reasons. The evidence records participation only. The benchmark exits with an error and omits the speedup for an incomplete series.
