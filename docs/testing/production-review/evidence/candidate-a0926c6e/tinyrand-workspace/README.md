# Five-crate Rust workload on two release builds

Both release builds reported dispositions for all 131 named cases from the unmodified Tinyrand 0.5.0 workspace at `8dd18ddefc9b057304441d9a7c112ba36d988dfe`. Native Cargo passed all 104 ordinary cases and 27 doctests. Distributed Cargo on each build passed 97 ordinary cases and all 27 standalone doctests. Stable Rust's WASI libtest skipped the same seven expected-panic cases. Both runs used the same signed test component bytes, source lock, sharder and observer, with fresh authenticated worker pairs. The clock-seeded case passed its ordinary invocation. The native-to-WASI disposition difference precluded the planned stochastic campaign. [Matched comparison](matched-comparison.json) · [Successor native comparison](successor-native-parity.json)

Full Cargo elapsed time was 405.893 s on bb70a619 and 92.430 s on a0926c6e (4.39×). The 27 sequential signed standalone guest readiness and dispatch calls took 383.496 s and 2.334 s summed. Fresh peer setup took 6.229 s and 62.596 s separately. Including the measured setup and Cargo phases gives 412.122 s and 155.026 s, respectively (2.66×). This was one pair on a shared Linux VM. A process snapshot during the successor run counted eight Rust compiler processes, ten Entanglement daemons and an active inference server. The raw reports retain cgroup and system load observations.
