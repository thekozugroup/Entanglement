All 128 preregistered `jaq` blocks completed on the `90beded5` Linux archive using the unchanged upstream revision `606164eb26420c892c9bac27f7daf77b7a406b6d`. Both raw worker responses and the independent verifier show the `now` assertion failing and then passing on a distinct authenticated worker in blocks 29 and 55. The workers agreed on the publisher-signed artifact and manifest digests. Across the full cohort, workers observed 69 initial passes, 57 failures on both attempts, and two recoveries. Native attempts observed 70 initial passes, 54 failures on both attempts, and four recoveries. No cohort block or native run was repeated.
