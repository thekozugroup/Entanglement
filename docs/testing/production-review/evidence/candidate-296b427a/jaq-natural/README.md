# A documented upstream flaky Rust case on real signed workers

The four-member MIT-licensed jaq workspace at `606164eb26420c892c9bac27f7daf77b7a406b6d` contains `jaq-core/tests/named.rs::now`. It takes the integer seconds from a system clock reading, evaluates jaq’s `now | round` against the real clock, and asserts equality. The upstream next commit removed this exact test with the message “remove flaky test”. The original public requirement does not specify a minimum number of packages. The search used five as a separate screening target. [Upstream test](https://github.com/01mf02/jaq/blob/606164eb26420c892c9bac27f7daf77b7a406b6d/jaq-core/tests/named.rs#L132-L137) · [Upstream removal](https://github.com/01mf02/jaq/commit/191e5e6780aad7fcc6295e3aced68bfd657eef14) · [Build, license and dependency provenance](build/provenance.json)

The protocol fixed 128 matched blocks per binary before collecting outcomes. Every block ran the same upstream case natively and on a signed WASI worker. It alternated ordering and first worker, retried genuine failures once immediately, and kept every attempt. No random seed or clock adjustment was used. The series stopped only at a preset infrastructure-error or time limit. The first instrument attempt on the old release passed the sharder a list where its exact filter expected a string. It recorded three native blocks, selected zero remote tests and stopped. Its incomplete receipt, raw data and failed aggregate are retained. The corrected reference and candidate cohorts each use the filter representation accepted by their actual sharder. These are co-located, distinct authenticated workers, and results measure real execution through the API. The compiler and adapter hashes, upstream lock and Cargo compiler artifact messages are in `build/`. Native Cargo’s full workspace run passed 112 ordinary cases plus one doctest.
