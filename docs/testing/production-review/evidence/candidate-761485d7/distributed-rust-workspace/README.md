## Additional unmodified upstream selector

The `stream_select` test in futures 0.3.32 runs 999 selections and requires at least 299 results for each of three branches. The upstream test author calls the assertion potentially flaky. The library seeds its thread-local generator from a deterministic hash of a process-local counter. The three fresh single-threaded Wasmtime invocations all passed on the first attempt. The worker start order alternated, retries were enabled and the test inputs and seed were unchanged. All three raw reports are retained.
