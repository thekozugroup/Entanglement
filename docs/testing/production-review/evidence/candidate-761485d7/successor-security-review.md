## Tailnet recovery

- **Bind and identity.** The tailnet-only service preserves the daemon's existing identity, configured Tailscale node-to-Entanglement-key mappings, bind address family and effective port. It checks the trusted local Tailscale CLI's bounded status response for a running backend and an exact local address in Tailscale's node space. A wildcard selects a local address in its stated family. An explicitly scoped address must return before binding. The service accepts a replacement only after checking that Iroh bound a single socket on the selected IP and port, with relays disabled. A cold offline start has no scheduler listener. Local daemon operations remain available while the supervisor waits for a verified bind. [Route selection](../../../../../crates/entangle-bin/src/remote/routes.rs) · [Supervisor](../../../../../crates/entangle-bin/src/remote/routes/supervisor.rs)
- **Endpoint lifecycle.** An ended QUIC accept loop or failed local bind revalidation withdraws the old endpoint and its route snapshot. The supervisor awaits endpoint retirement before replacement and backs off when status or bind fails. It retains the single task server, its active signed work leases, and its stream concurrency limits. The transport makes no second submission when a request loses its connection. Planned stop prevents publication after shutdown starts, joins the serving task and exits recovery. A concurrent replacement bind can finish as shutdown begins, and the stopped state drops that unpublished endpoint without running an accept service for it. [Daemon startup and shutdown](../../../../../crates/entangle-bin/src/main.rs) · [Task server construction](../../../../../crates/entangle-bin/src/remote.rs) · [Focused lifecycle tests](../../../../../crates/entangle-bin/src/remote/routes/supervisor/tests.rs)
- **Availability and authorization.** While a socket is bound, availability follows terminal accept-loop observations and periodic local Tailscale status checks. `mesh status` represents the local listener state, which can lag a local status change until checked. Individual destination reachability and authenticated inventory follow separate polls. Address hints carry no trust. The dispatcher binds the destination key to the expected peer; the server checks the current allowlist against the identity authenticated by QUIC and retains existing per-request signature and trust checks. A failed recovery clears listener status and its tailnet route hints. [Status method](../../../../../crates/entangle-bin/src/methods.rs) · [Admission and dispatch](../../../../../crates/entangle-scheduler/src/remote.rs)
