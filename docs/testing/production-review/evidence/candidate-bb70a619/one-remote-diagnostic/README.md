The primary seven-route comparison reported three misses against `864ae27b`. The local image route missed throughput by 0.2 percentage points while its p95 improved 17.3%. One-remote image p95 increased 6.3% and rate fell 7.0%. One-client greeting p95 increased 9.6%, with primary matched p95 ratios of 1.448, 1.018 and 0.844. These primary values remain the gate results. [Primary comparison](../performance.md) · [Prespecified diagnostic](plan.md)

The repeat verified the same released daemon bytes, same greeting test executable, same 24 JPEG inputs and same signed image component bytes. The image comparison used one fresh trusted worker per arm and checked its identity and checksum on every result. The worker used CPUs 0–2 and the coordinator and driver shared CPU 3. The greeting driver and its daemons inherited CPUs 0–3. All 1,728 measured image results and 49,152 measured greeting calls passed their existing checks. One-remote image tail latency warrants continued attention. Five of six pairs exceeded the 5% p95 allowance, with two just over 5.3%. The ratio of the two build medians was 1.043, while the median of the paired ratios was 1.068. The repeat's central throughput stayed inside the 5% allowance by either calculation, with three individually slower pairs. The 144,626–145,554-byte payloads were all below the 256 KiB upload-measurement threshold. Each remote call had one eligible recipient. Median measured coordinator CPU fell from 0.292 to 0.255 cores and worker CPU was close to flat at 2.438 and 2.459 cores. The data do not isolate a cause for the remaining tail signal.

The local image throughput and small greeting tail misses did not repeat in either central comparison. The individual distributions still have wide spreads. The greeting baseline reached 11.275 ms p95 in pair three. Its other p95s ranged from 2.433 to 3.198 ms, and candidate values ranged from 2.400 to 2.985 ms. Omitting that pair as a sensitivity check still gives 0.977 p95 and 0.968 throughput for the median matched ratios.

Host provisioning overlapped the first image pair. The candidate arm ran from 05:08:45.97 to 05:08:55.20 UTC, and the host listed `apt-get` and `dpkg` at 05:08:50 UTC. There was no compiler in the before-and-after censuses. CPU pinning controlled the tested processes and left external work subject to the same four-core quota. Setup, affinity, warmup and run ordering intentionally differ from the primary comparison, so this diagnosis cannot supply replacement gate results.
