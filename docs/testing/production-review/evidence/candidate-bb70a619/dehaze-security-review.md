## Input, execution and output

- The batch walker opens regular files through held directory descriptors, rejects symlinked descendants, skips sidecars and requires disjoint input/output trees. It stages the opened RAW bytes in a private temporary directory and hashes those exact bytes. At most 100,000 RAW paths and 128 nested directories are accepted. The two LibRaw tools receive fixed arguments. The wrapper resolves executables on the operator's absolute PATH, clears the child environment, serializes decoding, and enforces process memory, CPU, output-file size and wall-time limits. Both identify and render run natively under the operator's account. Deployment must supply trusted, maintained LibRaw tools. [File handling](../../../../../crates/entangle-cli/src/cmd/image/files.rs) · [Decoder](../../../../../crates/entangle-cli/src/cmd/image_raw.rs)
- The host permits up to 128 MiB of RAW input, 32 million **visible** raster pixels and 32,768 pixels per axis. Native conversion has a 2 GiB address-space limit. The signed Tier 1 guest receives only the cropped linear RGB16 tile and global atmospheric-light values. Its bounds are 16 MiB of encoded data, 2.5 million pixels and 4,096 per axis. Guest header checks precede decoded-raster allocation. Input with competing profiles or transparency is rejected. The guest and host now agree on the required position and parsed validity of gamma/chromaticity chunks. ## RPC and worker authorization

- The daemon processes local control connections from its owning UID on a mode-0600 Unix socket. It retains the 128-client ceiling, 60-second incomplete-read timeout and per-line limit of 64 MiB plus 64 KiB. Direct typed request/result parsing removes per-octet intermediate JSON values for compute arrays. The client binds the response to its request ID and protocol version, rejects ambiguous envelopes and caps compute reply line size. An ordinary batch also limits combined estimated raw tile bytes in flight to 32 MiB and concurrent calls to eight. This is an admission estimate. JSON text, raster storage, codec buffers and separate same-UID processes have their own memory costs. Other RPC methods have their own resource behavior. Eligibility still requires the requested ABI/plugin, current inventory, requested resources and the task allowlist. Selection cannot create trust. Before dispatch the address book consults current peer trust and binds the intended peer to its Iroh identity. The remote server also rechecks the authenticated submitter against its persisted allowlist before executing. The kernel verifies the signature over package and manifest on load.
