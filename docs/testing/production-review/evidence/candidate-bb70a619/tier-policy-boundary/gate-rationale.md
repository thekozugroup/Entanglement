# Tier-policy evidence and the agent-host gate

The `bb70a619` release applied a 5→3 ceiling twice with an empty affected set. The signed tier-3 Wasm plugin kept serving requests. The loader refused a signed native ELF at ceiling 5 because the native runner was unavailable, then rejected it on tier policy at ceiling 3. The separate 5→2 run exercised an affected set, including the default unload-and-disable action, cancellation and rollback, forced unload with per-plugin audit, and disabled state after restart. [Run receipt](receipt.json) · [Audit log](daemon-audit.log)

ATC-MAX-1 through MAX-3 require a loaded tier-5 agent-host before the 5→3 change. The manifest validator requires a native runtime at tier 5. The kernel verifies the package and checks the ceiling, then returns `NativeUnavailable` before registering a native package. Tier review builds its affected list from the loaded-plugin registry. [Acceptance checks](../../../../../architecture.md?plain=1#L1964) · [Manifest validation](../../../../../../crates/entangle-manifest/src/validate.rs#L190) · [Native admission](../../../../../../crates/entangle-runtime/src/kernel.rs#L294) · [Affected set](../../../../../../crates/entangle-runtime/src/kernel/tier_change.rs#L7)

The agent-host contract requires a sandboxed native subprocess and a working authenticated per-session MCP gateway. The current `AgentSession` snapshots, rewrites, and restores configuration, and `Gateway::start` returns `NotImplemented`. The tier-gated inference provider advertises its own streaming service outside the loaded-package registry. The three gates remain open until a genuine signed agent-host is loaded through the supported native lifecycle and subjected to the exact 5→3 checks.
