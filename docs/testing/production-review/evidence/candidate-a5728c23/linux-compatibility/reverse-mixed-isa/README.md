# AArch64 coordinator to x86-64 signed worker

The c19ef758 AArch64 CLI and daemon ran under QEMU user-mode and submitted one signed JSON Pointer task to the native a5728c23 x86-64 daemon. The ARM coordinator had no loaded plugins. The x86 worker rejected the package before the disposable ARM publisher was trusted, then loaded that single signed package. Both sides began with zero successful or failed Wasm calls. After the call the coordinator had zero invocations and the worker had exactly one success and zero errors. The selected peer matched the worker's generated identity and its output bytes equaled the independently computed JSON string containing the fresh nonce. Both source IDs and both pairs of released binary SHA-256 values matched before and after dispatch. The daemon process on ARM was identified as the recorded QEMU executable, and the x86 daemon was the native extracted ELF. The processes shared loopback inside one network-disconnected rootless container on an x86-64 Linux host. Both daemons exited cleanly, and Docker confirmed container removal.
