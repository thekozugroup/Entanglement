The isolated builder provisioned Debian-authenticated cross tools and disconnected its network before compiling. Cargo ran the full workspace with the original optimized release profile, explicit ARM target, frozen lockfile and offline registry. The compiler reported 11 minutes 32 seconds. The first completed-file export with Docker cp could not read the container’s mounted tmpfs. Streaming the same finished bytes from that mount with Docker exec produced SHA-256 hashes identical inside and outside the container. No recompilation was required. The emulated ARM coordinator then selected the native x86 worker with its own independently signed package. Only the native count increased, from 0 to 1. Both daemons shut down cleanly.
