# Ubuntu POSIX installer and signed workload

The Ubuntu 22.04 cold-build archive installed and ran on both Ubuntu 22.04 and 24.04. On 22.04, forcing a same-version update with the canonical Linux archive failed during the staged CLI version check because GLIBC_2.39 was unavailable. Both installed executables retained the portable archive's original SHA-256 values. The restarted daemon kept its peer identity and ran the same signed plugin on a new input. On 24.04, the same forced update replaced both executables with their exact canonical counterparts and preserved the peer identity and signed workload. All results use source a5728c230e5049556b806cae8597fe823dd67987. The tested portable tarball SHA-256 was 9a4c23b648ad26f23fa925c5171218094fb6b68247bcfbdc62dc19dca83d592d and the canonical tarball SHA-256 was 21f9efbc6a235f25d28235f5da7171c87b52dabd482c0ec63dd01fdc3557f611. The host checked both complete archives, SHA-256 and BLAKE3 sidecars, and each executable against its source-bound receipt. Each real installer requested its tarball and SHA-256 sidecar through a local file-backed curl adapter on the expected release URL paths. [Portable build receipt](../jammy-replay/jammy-linux-archive.json) · [Canonical receipt](../../linux-archive.json)

Each disposable x86-64 container used the stock Ubuntu dash shell, UID 65534, a read-only root filesystem, no network, no capabilities and a temporary writable installation prefix. The public fixture directory contained only the installer, adapter, test scripts, release inputs and catalog component. The installed CLI generated its own identity and signed the JSON Pointer package inside the disposable home. The first load was denied pending explicit publisher trust. Every successful invocation returned the expected JSON string through the installed daemon's Unix socket. This covers local Linux userlands and archive compatibility on one kernel. Registry publication, public release downloads and release signing are outside this experiment.

The initial canonical-only run passed. A second canonical-only run made both requested URLs and each empty-prefix assertion independently fatal in POSIX sh. The normalized matrix uses this stricter harness, which also drove the portable update tests. Both canonical observations and their fixture digests are retained. For a local replay, copy verify.py and curl-fixture.sh to a temporary directory, copy run-in-container-guarded.sh there as run-in-container.sh, and supply both source-bound archives and receipts to verify.py.
