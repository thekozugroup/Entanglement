# Biscuit compatibility for this release candidate

The workspace pins `biscuit-auth =7.0.0-alpha.4`. The previous stable release, 6.0.0, depends on the affected `crypto-bigint` 0.5 line through `elliptic-curve` 0.13. Its default Datalog macro also depends on the unmaintained `proc-macro-error2`. Disabling the macro on 6.0.0 fails to compile because that release unconditionally imports a macro-gated trait. The candidate uses `crypto-bigint` 0.7.11 and the upstream string-based Datalog API with regex and PEM support. [Timing advisory](https://rustsec.org/advisories/RUSTSEC-2026-0387.html) · [Macro advisory](https://rustsec.org/advisories/RUSTSEC-2026-0173.html) · [Upstream release](https://crates.io/crates/biscuit-auth/7.0.0-alpha.4)

**Rust callers.** The first parameter of `entangle_biscuits::mint` is now `&biscuit_auth::PrivateKey`. Code using `biscuit_auth::KeyPair::new()` should use `biscuit_auth::PrivateKey::new()`. The public key still comes from `.public()`. Applications passing Biscuit key types across crate boundaries must use the same version. The Entanglement workspace continues to target Rust 1.91.

**Serialized tokens.** The compatibility run on 2026-11-26 minted Ed25519 and P-256 tokens with both versions, appended signed Datalog checks, and verified each producer's bytes with the other version using its public key. Both directions accepted the expected capability and rejected a missing capability, an expired token, and an unsatisfied check. The check covers the token shapes exercised by Entanglement. Upstream still labels version 7 as a prerelease. The test suite retains the public version 6 vectors for future upgrades. [Wire fixtures](../../crates/entangle-biscuits/tests/fixtures/v6/README.md)

**Authorization.** Ordinary grants and bridge grants apply the typed authority, capability and expiry checks plus each signed Datalog check. Bridge grants also require the existing destination, lifetime and byte limits. The Datalog authorizer receives the token's facts and enforces bounded execution; a required positive predicate the verifier cannot supply fails the check. The repeatable policy suite runs with `cargo test --locked -p entangle-biscuits -p entangle-broker`.
